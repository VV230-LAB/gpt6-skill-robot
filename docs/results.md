# 实验结果与证据范围

[运行摘要 CSV](runs.csv)列出主要完整和中断运行。这里的记录来自此前封存的仿真实验。随仓库可复验的是几何工具及其合成输入测试。完整仿真实验的原始图像、动作轨迹、模型流水和训练参数存于原研究工作区。

## 上下文与工具复用

**冻结 C2** 在一次 Fast 堆碗运行中完成两次真实换线程，均从上一条动作的确认边界继续。该条成功用了 4,205,585 reported tokens／1005.19 秒，含维护及首次恢复窗口合计 941,232 tokens。非同期同档原生 R 也成功，7,722,160／1059.20 秒。C2 样本未缓存输入增加，操作路线也不同。可确认的结果是交接后继续执行、实际复用本回合资源，以及维护需要付出额外成本。

**RF1** 复用了源任务编写的碗沿多视图拟合器。新轨迹中的当前图像点被用于拟合，拟合结果进入接近目标，两组都达到局部持物终点。使用组仍多一次滑落重抓，reported tokens 高 49.40%，进程时间长 29.40%。对照组通过逐步视觉对准完成，因此这个实验没有观察到完整流程省工。

## 堆碗

**OBJ2** 是两条同期成功轨迹。原生 R 为 14,368,270 reported tokens／1780.326 秒，对象中层为 6,402,359／919.164 秒。对象中层执行 239/374 ACK，但两次抓取计划均停在过强的夹爪端点条件，后续搬放由 GPT 纠正完成。它支持有界执行能替代一部分工作，也指出了靠夹爪端点认定持物的缺口。

**EPR1** 在相同 `stack_bowls/layout0/seed0` 下重复五次。五条都达到原生终点，独立原图支持粗套叠、释放和撤离。四条通过预先固定的成本和时间联合门，门槛来自历史 OBJ2.B。均值为 4,222,970.6 reported tokens／723.013 秒。V1 至少两次失持和重新获取，完整进程 983.250 秒，超过时间门约 64 秒。五条严测右臂归位均未通过。有效相机投影随冻结执行器共同使用，其独立贡献尚未隔离。

**STD2** 是后来选定的普通档原生 R 堆碗参照，单条成功为 8,225,937／1085.178 秒／51 次已执行决策。普通档首次 STD1 也成功，为 14,928,729／1336.19 秒。两次均保留，EPR1 的历史 Fast 运行与这些普通档记录属于不同批次。

**MPE1** 验证 EPC 和 C2 能一起运行。两条均完整成功，四次交接后都接上动作。均值为 5,011,044／1102.279 秒，高于非同期 EPR1 均值。该结果支持恢复机制可用。两种方法之间的成本差异仍含物理返工和服务延迟。

## 堆积木与迁移

**EPC-BLK1** 的两条同期独立重置均原生成功。EPC 组相对原生 R 的 reported tokens 从 11,924,338 降到 4,132,782，外层授权从 60 到 22，完整时间从 948.218 到 873.265 秒。程序执行了 246/266 ACK。两组允许不同堆叠顺序，B 对实心积木使用任务所需的几何适配。每组只有一次运行。

**CORE2** 的普通档堆积木成功，3,429,386／722.248 秒／23 次外层授权。相对非同期普通档原生堆积木单例 6,246,364／725.122 秒／48 次已执行决策，观察到授权和 reported tokens 降低，完整墙钟几乎相同。核心替换接口有离线回归证据，正式轨迹未触发替换。

**CORE2 交换积木**到外层授权上限后未完成。原图支持三次搬放，整条任务所需的按钮和顺序阶段未得到完整注册证据。**CLS1 分类对照**的原生 R 因 Token 预留规则停止，EPC 组因遗留的 direct 步数上限与错误收尾提前停止。两条完成进度也不同，不能把截断前的用量拿来计算完整任务节省。

## 局部学生

Correction BC GRU 的两组各 13 条等量监督，B 只替换两条 MOVE。来自真实偏离的教师纠正确实完成了物体补移和独立检查。固定测试中两组 SHORT 和 HOLD 均 4/4，FULL 首步正确停止均 0/4。教师成功单独核算。

后续只补训 DONE 模式的 129 个参数，在 60 条新运行中复测冻结原端点与补训端点。测试 FULL 的正确停止在两组都从 0/4 到 2/4。B 的 SHORT 由 4/4 到 2/4，两个新增失败均在独立持物检查完成前停止。统一的全局计时允许交接前有效的检查 ACK 继续计入。该口径修订与学习增益分别核算。整体不退化门失败，未选择新端点。

## 如何读这些数字

- **Reported tokens** 包括服务报告的输入和输出。缓存是输入的子集，reasoning 是输出的子集。真实账单、未报告尾量和底层推理请求数未知。
- **ACK** 是实际执行确认的控制步。外层授权是 GPT 向宿主提交的操作请求，原生 R 与 EPC 一次授权可覆盖不同数量的 ACK。一条持续会话可包含多次推理和工具往返。
- **完整时间**为各报告的进程计时。CSV 的 `timing_scope` 保留计时口径。任务生命周期包括初始化、执行和收尾，进程嵌套时间只计一次。
- 原生成功、独立图像支持、严格归位和自主停止各有自己的分母。预算截断、服务故障和工程中断保留在原实验。不同任务、配置或服务档位分别比较。
- 研究问题还包括在重复使用中回收数据获取、标注、训练、工具维护与失败成本。这些批次未建立累计回本或持续学习收益。
